# 試験結果報告テキストのパース手順

ユーザーから「試験結果報告」のテキストデータを渡された場合、以下のルールに従って `data.js` の `exams` 配列に追加するデータ形式（JSON）に変換してください。

## データの基本構造
```javascript
{
  "studentId": "...", // 学籍番号
  "examName": "...", // 受験先（ルールに沿って成形）
  "stage": "...", // 1次試験、2次試験など
  "examContent": "...", // 試験内容（人物試験、適性検査など）
  "date": "...", // YYYY-MM-DD 形式。不明な場合は空文字 ""
  "status": "...", // 合格、不合格、結果待ち、辞退
  "remarks": "..." // 会場、時間、理由など
}
```

## パースルール
1. **「合格」の場合の分割処理（重要）**
   - 「結果：合格」となっているものは、その段階（例：1次試験）の「合格報告」と、次に控える「次段階（例：2次試験）の予定」の2つのデータに分割する。
   - **データ1（合格報告）**：`stage` は元の段階（1次試験など）、`status` は「合格」。`date` や `examContent`、`remarks` は空にする（次回の情報であるため）。
   - **データ2（次回予定）**：`stage` は次の段階（2次試験など）、`status` は「結果待ち」。テキストの「試験日程」や「会場」などの情報を `date`, `examContent`, `remarks` に振り分ける。

2. **`examName` の表記ルール**
   - 「市役所」「町役場」は事務職を意味するため削除し、「○○市」「○○町」とする（例：橋本市役所 → 橋本市）。
   - 「国家税務職」は「国家税務」に統一する。
   - 消防などの場合は、市町村名の後に半角スペースを入れて表記する（例：橋本市消防 → 橋本市 消防）。

3. **`examContent` の表記ルール**
   - 「事務職」「行政」「行政Ⅲ種」などは単なる採用区分や自治体の表記揺れなので無視し、空文字にする。
   - 「人物試験」「個人面接」「集団討論」など、具体的な試験手法が書かれている場合は `examContent` に記載する。

4. **その他のルール**
   - 「受験しなかった」は `status` を「辞退」とする。
   - 日時や会場、受けなかった理由はすべて `remarks` に入れる。
